Song Query (client-side) — JSON output only

Usage (paste in address bar):

  • ?q=3%20Praise%20the%20Lord
  • ?q=3
  • ?q=Praise%20the%20Lord
  • ?sno=1 or ?q=1%20Amazing%20Grace

If you open the page without query params, this help will remain visible. If you supply q or sno the script will output only JSON (no HTML wrapper) by navigating to a data:application/json URL.
